# 정적 규칙 fixtures

규칙마다 `<규칙 ID에서 krds/를 뺀 이름>/fail.tsx`·`pass.tsx`가 있다.

- `fail.tsx`: 위반이 나와야 하는 줄에 `✗`를 적는다. 한 줄에 위반이 둘이면 `✗✗`다. 테스트는 줄마다 `✗` 개수와 위반 개수를 견준다.
- `pass.tsx`: 위반이 하나도 나오면 안 된다.
- 주석 자리: JS 줄 끝은 `// ✗`, JSX 여는 태그 안은 `/* ✗ */`, JSX 자식 자리는 `{/* ✗ */}`.
- 검사 대상 레포의 코드를 옮기지 않는다. 같은 패턴을 새로 짓는다.
